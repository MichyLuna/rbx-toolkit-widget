## Cosa mostra

| | |
|---|---|
| 👥 **Contatore amici** | Numero di amici Roblox con barra verso il tuo obiettivo |
| 🎉 **Nuovo amico!** | Avviso animato con avatar quando accetti qualcuno (anche dalla chat con `!add`) |
| 🎮 **Tocca a te!** | Chiama il prossimo spettatore della coda "Gioca con me" (`!join`) |
| 💬 **Info** | Risposte ai comandi `!roblox` e `!gioco` |
| 🙋 **Aggiungimi** | Riquadro fisso con il tuo username Roblox |

Formato orizzontale o **verticale per TikTok**, colore, suono e testo personalizzabili.

## Come si usa

1. Installa l'estensione **RBX Toolkit**
2. Dashboard → **Strumenti streamer → Widget per OBS** → attiva e premi **Copia link**
3. In OBS: **Fonti → + → Browser**, incolla il link nel campo URL, 460 × 220
4. Premi **Invia avviso di prova** per controllare

> Il link contiene un codice personale (`#k=…`): non mostrarlo in live.

## Privacy

Il widget riceve gli eventi in tempo reale da [ntfy.sh](https://ntfy.sh) sul canale indicato nel link.
Non raccoglie dati, non usa cookie e non ha accesso all'account Roblox o TikTok.
