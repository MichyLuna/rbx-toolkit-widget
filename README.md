# RBX Toolkit – Widget OBS

Widget per OBS dell'estensione **RBX Toolkit** (contatore amici Roblox, avvisi "Nuovo amico!", coda "Gioca con me").

Non si usa da solo: il link completo (con il codice personale `#k=...`) si copia dalla dashboard dell'estensione,
sezione **Strumenti streamer → Widget per OBS**, e si incolla in OBS come **fonte Browser**.

Il widget riceve gli eventi in tempo reale tramite [ntfy.sh](https://ntfy.sh) sul canale indicato nel link.
Non raccoglie dati e non ha accesso all'account Roblox.
