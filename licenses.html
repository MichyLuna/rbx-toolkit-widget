ExtPay.js 3.1.2

Library by Glench used to handle the optional Pro subscription through ExtensionPay.
Source: github.com/Glench/ExtPay · npm: extpay

License: the project's LICENSE file states LGPL-3.0, while its package.json declares AGPL-3.0-or-later. Full texts: GNU LGPL v3 (which incorporates the GNU GPL v3) and GNU AGPL v3.

The library is shipped unminified as separate files inside the extension (vendor/extpay-content.js, identical to the original dist/ExtPay.js, and vendor/extpay.module.js, the same file with a single export default ExtPay; line added at the end so it can be loaded as an ES module). You can read and replace these files in the installed extension. The source of our modified copy is the file itself.
